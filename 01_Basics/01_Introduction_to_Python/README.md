# 01 — Introduction to Python

## 1. Python kya hai?

**Professional Definition:** Python is a high-level, general-purpose programming language known for readable syntax and a large ecosystem of libraries.

**Hinglish:** Python ek easy-to-read programming language hai jiska use web development, automation, data analysis, AI/ML, scripting aur bahut saare areas mein hota hai.

## 2. Programming kya hoti hai?

Programming ka simple meaning hai **computer ko instructions dena** taaki computer hamare liye koi task perform kare.

Real life mein agar hum kisi ko chai banane ke steps batate hain, to computer programming mein bhi hum task ko instructions mein break karte hain.

## 3. Python kyun seekhein?

- Syntax beginner-friendly hai.
- Code readable hota hai.
- Automation se AI/ML tak use hoti hai.
- Bahut bada library ecosystem hai.
- Rapid development ke liye useful hai.

## 4. First Python Program

```python
print("Hello, Python!")
```

### Output

```text
Hello, Python!
```

`print()` screen par information display karne ke liye use hota hai.

## 5. Basic Example

```python
# Student ka naam screen par print kar rahe hain
print("Rahul")

# Student ki age print kar rahe hain
print(24)
```

## 6. Multiple Values Print Karna

```python
name = "Amit"
age = 21

print("Name:", name)
print("Age:", age)
```

## 7. User se Input Lena

```python
# User se naam input le rahe hain
name = input("Enter your name: ")

# User ke naam ke saath greeting print kar rahe hain
print("Hello", name)
```

**Important:** `input()` se normally value string ke form mein milti hai.

## 8. Comments

Comment code ka explanation hota hai. Python interpreter normal comments ko execute nahi karta.

```python
# Ye single-line comment hai
print("Python is easy to learn")
```

## 9. Intermediate Example

```python
# User se basic information le rahe hain
name = input("Enter your name: ")
city = input("Enter your city: ")

# Collected information display kar rahe hain
print("Student Name:", name)
print("City:", city)
```

## 10. Common Mistakes

❌ `Print("Hello")` — Python case-sensitive hai.

✅ `print("Hello")`

❌ String ke quotes miss karna:

```python
print(Hello)
```

✅

```python
print("Hello")
```

- Python ek high-level programming language hai.
